## Batasan dan Keputusan Rilis

Rilis ini sengaja berstatus **prerelease**. APK Android telah ditandatangani untuk
release, tetapi installer Windows belum memiliki Authenticode karena secret
`WINDOWS_CODE_SIGNING_PFX_BASE64` dan `WINDOWS_CODE_SIGNING_PASSWORD` belum tersedia.
Auto-updater produksi mengabaikan prerelease ini sehingga pengguna produksi tidak
akan menerima installer Windows unsigned secara otomatis.

Automated gates membuktikan build dan alur yang dicakup test, tetapi tidak menggantikan
UAT pada perangkat fisik, printer/scanner nyata, kualitas jaringan lapangan,
rekonsiliasi terhadap data legacy, dan persetujuan pemilik proses bisnis.
