# Demo dan sample plan

`demo.mitrainap.id` bersifat reserved, resettable, sample-only, non-billable, menampilkan banner DEMO, memakai credential palsu, payment fake, dan outbound notification sandbox.

Sample minimum: chain/brand/property, buildings/floors, 5 room types, 40+ rooms, facilities/outlets, guests/company/agent, rates/restrictions, reservations pada seluruh lifecycle, arrivals/in-house/departures, HK/maintenance tasks, folio/deposit/POS room charge, group/MICE, long stay/owner, channel fake jobs, night-audit exception dan report snapshots.

Generator harus deterministic dengan seed/profile/version, idempotent, menyimpan label sample, tidak memasukkan PII nyata, dan dapat diverifikasi/reset tanpa menyentuh production tenant.
